# REST API проєкту Vectra IT Service

Базова адреса: `http://localhost:3000/api`

| # | Ресурс | Метод | Призначення | Успіх | Помилки |
|---|---|---|---|---|---|
| 1 | `/services` | GET | перелік усіх ІТ-послуг | 200 | 500 |
| 2 | `/services/:id` | GET | картка конкретної послуги | 200 | 404 |
| 3 | `/requests` | GET | перелік заявок із фільтрацією | 200 | 400 |
| 4 | `/requests/:id` | GET | деталі конкретної заявки | 200 | 404 |
| 5 | `/requests` | POST | створення нової заявки | 201 | 400, 422 |
| 6 | `/requests/:id` | PUT | повне оновлення заявки | 200 | 404, 422 |
| 7 | `/requests/:id` | DELETE | скасування/видалення заявки | 204 | 404 |
| 8 | `/managers` | GET | перелік персональних менеджерів | 200 | 500 |
| 9 | `/statuses` | GET | список можливих статусів заявок | 200 | 500 |

## Параметри GET /requests
| Параметр | Тип | Приклад | Опис |
|---|---|---|---|
| `status_id` | int | `?status_id=1` | фільтр за ідентифікатором статусу |
| `service_id` | int | `?service_id=4` | фільтр за обраною послугою |
| `q` | string | `?q=Денис` | пошук за ім'ям замовника або ID |
| `sort` | enum | `?sort=created_at_desc` | сортування за датою створення |
| `page` | int | `?page=1` | номер сторінки пагінації |
